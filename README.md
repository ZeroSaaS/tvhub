# tvhub: TizenBrew loader

A [TizenBrew](https://github.com/reisxd/TizenBrew) module that opens a self-hosted
TV Hub page from the local network. It contains no app code; the page is served by
the home server at the `websiteURL` in `package.json`.

Add it in TizenBrew → Module Manager → Add module → GitHub → `ZeroSaaS/tvhub`.
